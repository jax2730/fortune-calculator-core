# Fortune Calculator Core

Public, sanitized calculation core extracted from a private local application.

This repository contains only reusable Bazi and Ziwei calculation modules and safe unit tests. The private application, databases, accounts, conversations, prompts, reports, device media access, upload pipeline, monitoring, deployment configuration, APK files, and user data are intentionally excluded.

## Development

```powershell
corepack pnpm install
corepack pnpm test
corepack pnpm typecheck
```
